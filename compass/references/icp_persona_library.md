# ICP Persona 库（ICP Persona Library）

> Step 5 渠道打法使用的 persona 库。每条 VOC 必须打 persona 标签。
> 这是多视角预研究（STORM 借鉴）的角色定义。

## Persona 定义

### 1. procurement_officer（采购官）

- **角色**：B2B 采购决策者，关注 TCO / 合规 / 供应商资质
- **KPI**：采购成本下降 %、供应商交付准时率、合规事件数
- **典型痛点**：多供应商比价复杂、合规审计繁琐、SKU 切换风险
- **价格敏感度**：高（但看 TCO 不看 list price）
- **价值感知**：中（看功能但更看合规与服务）
- **推荐渠道**：官方授权经销商、集采招标
- **决策权重**：高（通常一票否决）

### 2. cfo（财务总监）

- **角色**：财务把关者，关注 ROI / 现金流 / 折旧周期
- **KPI**：CAPEX/OPEX 占比、回本周期、资产周转率
- **典型痛点**：CAPEX 一次性投入大、折旧周期与生命周期不匹配
- **价格敏感度**：高（看回本周期）
- **价值感知**：高（看长期 ROI）
- **推荐渠道**：租赁 / 订阅模式、分期方案
- **决策权重**：高（金额超阈值时一票否决）

### 3. it_admin（IT 管理员）

- **角色**：技术评估者，关注 MDM / 集成 / 运维
- **KPI**：MDM 部署效率、故障率、运维工单数
- **典型痛点**：批量配置复杂、远程管理弱、固件更新不一致
- **价格敏感度**：中（看运维成本）
- **价值感知**：高（看易管理性）
- **推荐渠道**：官方技术支持、有 SDK 的品牌
- **决策权重**：中（技术否决权，但通常不主导购买）

### 4. channel_partner（渠道商）

- **角色**：经销商 / 集成商，关注 margin / 账期 / 培训
- **KPI**：毛利率、库存周转、返点收益
- **典型痛点**：margin 薄、品牌方直营抢客户、培训成本高
- **价格敏感度**：极高（看 margin %）
- **价值感知**：中（看品牌拉力）
- **推荐渠道**：自己是渠道方
- **决策权重**：高（在分销模式下一票否决是否主推）

### 5. competitor_sales（竞品销售）

- **角色**：竞品前线销售，关注话术 / 主推 SKU / 客户异议
- **KPI**：成单率、客单价、客户流失率
- **典型痛点**：被对比、被压价、被替换
- **价格敏感度**：N/A（自己定价）
- **价值感知**：N/A
- **推荐渠道**：N/A
- **决策权重**：N/A（这是竞品的视角，用于反向推导他们的 GTM 策略）

### 6. industry_analyst（行业分析师）

- **角色**：第三方分析师，关注品类趋势 / 市场份额 / 技术演进
- **KPI**：报告引用率、预测准确率
- **典型痛点**：数据不全、厂商 self-report 偏差
- **价格敏感度**：N/A
- **价值感知**：N/A
- **推荐渠道**：N/A
- **决策权重**：N/A（用于提供品类背景与趋势判断）

### 7. end_user（终端用户）

- **角色**：实际使用者（收银员 / 服务员 / 仓管员），关注易用性 / 稳定性
- **KPI**：操作错误率、效率、投诉数
- **典型痛点**：界面复杂、卡顿、外设不识别
- **价格敏感度**：低（不关心价格）
- **价值感知**：高（看日常体验）
- **推荐渠道**：N/A
- **决策权重**：低（通常不参与购买决策，但影响续约）

## 多视角预研究问题模板（STORM 借鉴）

Step 5 必须从每个 persona 视角提问，禁止只从「我方」视角分析。

### procurement_officer 视角
- 我为什么选竞品 A 而不选主品？合规资质差在哪？
- 多供应商比价时竞品 A 的优势 / 劣势是什么？
- SKU 切换时竞品 A 的退市政策如何？

### cfo 视角
- 竞品 A 的回本周期 vs 主品谁更短？
- 竞品 A 是否提供租赁 / 订阅？CAPEX vs OPEX 哪个更优？
- 折旧周期结束后竞品 A 残值如何？

### it_admin 视角
- 竞品 A 的 MDM 支持如何？批量部署要多久？
- 竞品 A 固件更新频率与一致性如何？
- 竞品 A SDK 开放度如何？二次开发成本？

### channel_partner 视角
- 推竞品 A 的 margin 多少？vs 主品呢？
- 竞品 A 是否直营抢客户？渠道冲突如何？
- 竞品 A 培训与认证体系如何？

### competitor_sales 视角（反向推导竞品 GTM）
- 竞品 A 销售主推哪个 SKU？话术是什么？
- 竞品 A 销售遇到主品对比时如何反驳？
- 竞品 A 销售的 KPI 结构（提成 / 返点）暗示什么？

### industry_analyst 视角
- B2B 商用平板品类趋势？
- 竞品 A 的市场份额变化？
- 下一代技术演进对竞品 A vs 主品的影响？

### end_user 视角
- 收银员 / 服务员实际使用竞品 A 的体验？
- 竞品 A 故障率与维修响应如何？
- 竞品 A 界面易用性 vs 主品？

## persona 标签规则

Step 5 的 `voc_extract.py` 必须为每条 VOC 打 persona 标签：

| 评论上下文信号 | persona |
|---|---|
| 「our procurement team」「RFQ」「vendor evaluation」 | procurement_officer |
| 「budget」「ROI」「depreciation」「CAPEX」 | cfo |
| 「MDM」「deploy」「firmware」「SDK」「integration」 | it_admin |
| 「margin」「resell」「distributor」「partner program」 | channel_partner |
| 「I use it daily」「my shift」「checkout」「customer」 | end_user |
| 无法判断 | null（标 `⚠️ persona 未识别`） |

## 决策权重矩阵

不同 persona 在不同决策场景下的权重：

| 决策场景 | procurement | cfo | it_admin | channel_partner | end_user |
|---|---|---|---|---|---|
| 新品采购 | 高 | 高 | 中 | - | 低 |
| 续约 / 复购 | 中 | 中 | 高 | - | 高 |
| 渠道拓展 | - | - | - | 极高 | - |
| 退市切换 | 高 | 高 | 高 | 高 | 中 |
| 价格调整 | 高 | 高 | - | 极高 | - |

Step 5 输出 Message House 时必须按决策场景选择目标 persona，禁止「对所有 persona 都说一样的话」。
